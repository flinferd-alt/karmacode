# Коды Кармы - Персональный разбор

Одностраничное приложение (SPA) для персонального разбора кодов кармы на основе даты рождения.

## 🌟 Описание проекта

Приложение рассчитывает 4 ключевых кода кармы (КЛК) по дате рождения и предоставляет подробное описание каждого кода, включая:
- Сильные стороны
- На что обратить внимание
- Кармические задачи
- Испытания жизни
- Рекомендации
- Аффирмации

## ✨ Основные функции

### 1. Персональный разбор кодов кармы
- Автоматический расчёт 4 кодов кармы по дате рождения
- Подробное описание каждого кода
- Интерактивные карточки с раскрывающимися секциями

### 2. Урок года
- Описание 22 возможных уроков года
- Текст "9 признаков того, что Карма Включилась"
- Рекомендации и аффирмации для каждого урока

### 3. Калькулятор кармической связи
- Расчёт кодов для двух дат рождения
- Визуализация в виде треугольников
- Подсветка совпадающих кодов (кармическая связь)
- Экспорт результатов в PDF
- Поделиться в социальных сетях (VK, Telegram)

### 4. Запись на эфиры
- Добавление событий в Google Calendar, Яндекс Календарь, Apple Calendar
- Выбор всех событий или конкретного эфира

## 🔗 Интеграция с Автопилотом

### Передача данных через URL

Приложение поддерживает два формата передачи параметров:

#### 1. Query параметры
```
https://ваш-домен.ru/?code1=2&code2=1&code3=4&code4=3
```

#### 2. Hash параметры
```
https://ваш-домен.ru/#code1=2&code2=1&code3=4&code4=3
```

### Параметры

- `code1` - первый код кармы (КЛК 1)
- `code2` - второй код кармы (КЛК 2)
- `code3` - третий код кармы (КЛК 3)
- `code4` - четвёртый код кармы (КЛК 4)
- `lesson` - код урока года (1-22)
- `calc=1` - открыть калькулятор кармической связи

### Примеры URL

**Основная страница с кодами:**
```
https://annabaryshnikova.com/karma/?code1=2&code2=1&code3=4&code4=3
```

**Страница урока года:**
```
https://annabaryshnikova.com/karma/?lesson=7
```

**Калькулятор кармической связи:**
```
https://annabaryshnikova.com/karma/?calc=1
```

## 📊 Формулы расчёта кодов

### Код рождения (КР)
День рождения, если > 22, то вычитаем 22

### Код судьбы 1 (КС1)
Сумма всех цифр даты рождения, приводим к числу от 1 до 22

### Код судьбы 2 (КС2)
Сумма дня, месяца и года, приводим к числу от 1 до 22

### КЛК 1-4
Разности между приведёнными к 1-22 значениями дня, месяца и года

## 🐛 Решение проблем

### Ошибка при сборке на Windows
```
SyntaxError: missing ) after argument list
```

**Решение:**
1. Переустановите зависимости:
   ```bash
   rmdir /s /q node_modules
   del package-lock.json
   npm install
   ```

2. Или установите Node.js LTS версии (20.x или 22.x)

### Сайт не открывается на хостинге
```
GET https://.../assets/index-xxx.js net::ERR_ABORTED 404
```

**Решение:**
1. Убедитесь, что в `vite.config.js` установлено `base: "./"`
2. Пересоберите проект: `npm run build`
3. Загрузите все файлы из `dist/` на хостинг
4. Очистите кэш браузера: `Ctrl+Shift+R`
